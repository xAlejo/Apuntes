# TITULOS Y ENCABEZADOS
Para crear títulos de diferentes tamaños, usa el símbolo numeral (#) seguido de un espacio. Cuantos más numerales, más pequeño será el título (desde H1 hasta H6).
```Markdown
# Título principal
## Subtítulo
### Sección
#### Subsección
```
# Formato de texto
```Markdown
Negrita: **texto en negrita** o __texto en negrita__ -> texto en negrita

Cursiva: *texto en cursiva* o _texto en cursiva_ -> texto en cursiva

Tachado: ~~texto tachado~~ -> texto tachado

Combinados: ***negrita y cursiva*** -> negrita y cursiva
```
# Espacios, Saltos de linea y lineas Divisorias
Para controlar la estructura visual de tu texto:
```Markdown
* Salto de línea / Espacio vertical: <br> (genera un salto de línea limpio, muy útil para separar párrafos o elementos que Markdown junta por defecto).

* Espacio en blanco horizontal: &nbsp; (equivale a un espacio de no separación, útil si necesitas dejar espacios vacíos horizontales).

* Línea divisoria (Horizontal Rule): Tres guiones (---), asteriscos (*) o guiones bajos (___`) en una línea vacía crean una línea horizontal:
```
---
# Listas y Tareas (Checklists)
Ideal para organizar notas o pasos a seguir en un proyecto:
* Listas con viñetas: Usar asteriscos *, guiones - o signos mas +
```Markdown
* Elemento 1
* Elemento 2
```
* Listas numeradas: Usar numeros seguidos en un punto
```Markdown
1. Primer paso
2. Segundo paso
```
* Tareas interactivas (Checklist): Excelente para organizar pendientes en GitHub.
```Markdown
- [x] Tarea completada
- [ ] Tarea pendiente
```
